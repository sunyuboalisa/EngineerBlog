 # 开发环境
nvm
nodejs

# 基本用法
```
nvm node_mirror <url>
nvm npm_mirror <url>

nvm list available
nvm list

nvm install <version>
# 安装最新 LTS 版本
nvm install --lts

nvm use <version>

nvm current

nvm uninstall <version>
```

## 不同项目配置不同 nodejs 版本

# 脚手架


```
# 创建并进入项目文件夹
mkdir ts-log-wrapper && cd ts-log-wrapper

# 初始化 package.json
pnpm init

# 安装 TypeScript 开发依赖
pnpm add typescript ts-node @types/node -D

# 初始化 tsconfig.json
pnpx tsc --init
```
