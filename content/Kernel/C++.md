## 树
### 二叉树

### BST
兼具有序数组和链表的优点，可快速查找和插入。
他的特点是
- 每个节点最多有两个子节点
- 左子节点的值 < 父节点的值 < 右节点的值
缺点：在插入删除操作次数多后，树会退化成线性结构
### AVL
AVL 是一种自平衡 BST。每当 AVL 树失去平衡，它都会通过旋转来实现平衡，确保高度为 O(log n)
特点是：
- 左右子树深度差不超过1
术语：
- 平衡因子：左子树的深度减去右子树的深度

#### 旋转
|                  |            |                   |
| ---------------- | ---------- | ----------------- |
| **LL旋转**（右旋）     | 插入在左子树的左子树 | 对当前节点右旋           |
| **RR旋转**（左旋）     | 插入在右子树的右子树 | 对当前节点左旋           |
| **LR旋转**（先左旋再右旋） | 插入在左子树的右子树 | 先对左子节点左旋，再对当前节点右旋 |
| **RL旋转**（先右旋再左旋） | 插入在右子树的左子树 | 先对右子节点右旋，再对当前节点左旋 |

### 红黑树
红黑树是一棵满足以下五个性质的二叉搜索树：

1. 每个节点是红色或黑色；
2. 根节点是黑色；
3. 所有叶子节点（NIL）为黑色；
4. 不存在两个连续的红色节点（即红色节点的子节点必为黑色）；
5. 任意节点到其子孙叶子节点的所有路径上的黑色节点数目相同（黑高一致）。

满足上述性质的红黑树高度为 O(logn) ，支持高效查找、插入与删除。
### B 树
常用于创建数据库。
特点：
- 树中每个节点至多有m棵子树
- 若根节点不是叶子节点，则至少有两棵子树
- 除根之外的所有非终端节点至少有 $\lceil m/2 \rceil$ 棵子树
- 所有的非终端节点中包含下列信息数据
$$
\left(n, A_0, K_1, A_1, K_2, A_2, \cdots, K_n, A_n\right)
$$
其中：$K_i(i=1,...,n)$为关键字，且$K_i<K_i+1(i=1,...,n-1)$; $A_i(i=0,...,n)$为指向子树根节点的指针，且指针$A_i-1$所指子树中所有节点的关键字均小于$K_i(i=1,...,n)$，$A_n$所指子树中所有节点的关键字均大于$K_n$，$n(\lceil m/2 \rceil-1\le n \le m-1)$为关键字的个数
- 所有的叶子节点都出现在同一层，并且不带信息
