# 邮箱
邮箱传输四部曲
- **寄信端 (MUA - 始发站)**： 发送者使用邮件客户端（如 Outlook、Gmail App）撰写并点击发送。这是邮件旅程的起点。
    
- **中转站 (MTA - 运输员)**： 邮件进入传输阶段。邮件传输代理负责在不同的服务器之间“接力”，直到将邮件送达目标服务器所在的网络。
    
- **分拣处 (MDA - 派送员)**： 当邮件到达目的地服务器后，由邮件投递代理将其存入收件人的特定“信箱”（服务器存储空间）。
    
- **收信端 (MUA/协议 - 签收站)**： 收件人通过 **POP3**（下载并通常从服务器删除）或 **IMAP**（双向同步）协议，从服务器调取并阅读邮件。

一般要搭建一个邮箱服务至少有下面三类服务
- **发信服务器 (SMTP 服务器)**：通常使用 **Postfix** 或 **Sendmail**。这是你的 **MTA**，负责把信寄出去，并接收外面的来信。
    
- **收信服务器 (POP3/IMAP 服务)**：通常使用 **Dovecot**。它允许用户连接服务器读取邮件。
    
- **身份验证机制**：配置 SASL 认证，确保只有拥有账号的人才能通过你的服务器发信，防止服务器变成“垃圾邮件中转站”。

## 安装 postfix以及配置SASL
```
sudo apt install postfix

sudo dpkg-reconfigure postfix

sudo postconf -e 'home_mailbox = Maildir/'

sudo postconf -e 'smtpd_sasl_type = dovecot'
sudo postconf -e 'smtpd_sasl_path = private/auth'
sudo postconf -e 'smtpd_sasl_local_domain ='
sudo postconf -e 'smtpd_sasl_security_options = noanonymous'
sudo postconf -e 'broken_sasl_auth_clients = yes'
sudo postconf -e 'smtpd_sasl_auth_enable = yes'
sudo postconf -e 'smtpd_recipient_restrictions = \
permit_sasl_authenticated,permit_mynetworks,reject_unauth_destination'

sudo apt install dovecot-core

telnet mail.example.com 25
# 应该收到 ehlo mail.example.com


```
