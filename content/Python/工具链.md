 # 开发环境
## pipx
```
brew install pipx (mac)
sudo apt install pipx  (23.04 +)
python3 -m pip install --user pipx  (other distributions of linux)
py -m pip install --user pipx ( windows )

pipx ensurepath
```
## uv
```
pipx install uv
pipx ensurepath

pip install uv

source ~/.bashrc

echo 'eval "$(uv generate-shell-completion bash)"' >> ~/.bashrc
echo 'eval "$(uvx --generate-shell-completion bash)"' >> ~/.bashrc

pip install --upgrade uv
```

| os      | 配置地址                     |
| ------- | ------------------------ |
| windows | %APPDATA%\uv\uv.toml     |
| linux   | 用户目录下/.config/uv/uv.toml |

配置如下
```
# 1. 下载镜像
python-install-mirror = "http://nexus.yxtzx.local/repository/raw-proxy-python-build/"

# 2. 信任内网源
allow-insecure-host = ["nexus.yxtzx.local"]

# 3. 索引匹配策略
index-strategy = "unsafe-best-match"

# 4. 定义索引
index-url = "http://nexus.yxtzx.local/repository/pypi-hosted-cu130/simple/"
extra-index-url = ["http://nexus.yxtzx.local/repository/pypi-group/simple/"]
```

# 基本用法
## uv 基本用法

```
uv venv --python 3.12.0
uv init project_name

uv python install 3.12 3.11
uv python pin version

uv run script_name
uv add package
uv remove package

uv sync
uv build
uv publish
```

## pipx 基本用法
```
pipx install PACKAGE

pipx list
```

# Workspace
project.toml
```
[project]
name = "albatross"
version = "0.1.0"
requires-python = ">=3.12"
dependencies = ["bird-feeder", "tqdm>=4,<5"]

[tool.uv.sources]
bird-feeder = { workspace = true }
tqdm = { git = "https://github.com/tqdm/tqdm" }

[tool.uv.workspace]
members = ["packages/*"]

[build-system]
requires = ["uv_build>=0.10.9,<0.11.0"]
build-backend = "uv_build"
```
