我们现在学的知识都是前人在解决了遇到的问题后总结下来的经验，并归纳出的一套成体系的方法。但是教材上只记录了总结后的东西，没有前人当时的场景以及遇到的问题这部分的相关记录。
如果只看教材的话，这种方式和人的学习模式是相反的，我们都是遇到问题，慢慢摸索怎么解决，教材上直接放的是答案，但是并没有将这个答案对应哪个问题。 因此需要有人告诉后来者，哪些问题对应教材上的哪些知识。
此后我们在实际中遇到问题，摸索着前进并解决了，事后将这些经验总结归纳，又是新的知识。愿感兴趣的人分享自己的经历以及总结的知识




现阶段应该只是文明诞生的启蒙时期，还没有清晰的轮廓，大部分事情都具有歧义是不规则的。慢慢地总要有统一的发展路线，比如科学也有特定的成长阶段，假设根据能力值分为9级，什么样的情况下算1级，以后最后到9级。  这种等级审核必定要没有人的干扰和评价。有了这种体系的形成，之后文明才会迅速发展，不再混沌。
